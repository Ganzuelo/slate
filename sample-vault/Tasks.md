# Tasks

Tasks stay in your notes. This page collects them with a query. Click a checkbox to complete it, the pencil to edit it, or the source link to jump to its note. In live preview, use **Edit query** to change the search, then move the cursor outside the block to see the results.

```tasks
not done
group by filename
sort by due
sort by priority
```

## Try it

- [ ] Plan the week #planning ⏫
- [ ] Weekly review #planning 🔁 every Friday 📅 2026-10-30
- [ ] Read a chapter #reading ⏳ 2026-10-30

Use **New task** in the Tasks view, or **Edit task at cursor** in the command palette. **Ctrl+Enter** completes or reopens the task at the cursor. Task changes in the editor support Undo and follow your autosave setting.
